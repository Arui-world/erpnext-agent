# Agent 运行时与模型连通性开发记录

> 完成日期：2026-08-09
> 对应阶段：ERPNext Agent 最小只读运行时

## 本次目标

依据 `ERPNext-Agent-开发方案.md` 和既有开发进度，完成 MCP ToolBase、用户专属 Agent
运行时和流式聊天接口，并使用现有模型环境变量发起真实请求，确认能够获得千问回复。

## 已完成内容

- 新增 `ERPNextMCPTool(ToolBase)`，原样保留 MCP `inputSchema`，只消费规范化后的
  `structuredContent`；
- 过滤 MCP 元数据并把业务文本标记为 `untrusted_business_data`，领域失败返回错误
  ToolChunk；
- 从服务器发现的 13 个工具构造 Orchestrator、Data、Action、Patrol 四套物理隔离 Toolkit；
- Data/Patrol 不持有写工具，Orchestrator 不持有 ERPNext 工具，写工具只存在于 Action
  Toolkit 且权限为不可绕过的 `ASK`；
- 新增请求级 `AgentRuntimeFactory`：读取当前用户加密 OAuth token、核对 MCP 身份、创建全新
  Agent/Toolkit，避免跨用户共享 token 与对话状态；
- `POST /api/v1/chat` 已接入 Data/Patrol 的 AgentScope 回复循环；
- `POST /api/v1/chat/stream` 已接入文本增量、工具开始/结束和回复完成 SSE；
- Action 聊天请求仍停在持久化审批入口，不会直接调用草稿写工具；
- `/health/ready` 的 `agent_chat_runtime` 已反映当前模型与运行时代码可用状态；
- 新增独立模型连通性入口 `python -m erpnext_agent.model_smoke`。
