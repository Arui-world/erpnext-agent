# Agent 前端对话页面开发记录

> 完成日期：2026-08-09
> 对应阶段：模型连接与 ERPNext Agent 人工测试工作台

## 本次目标

提供一个可以直接在浏览器中使用的简洁 Agent 页面，方便手工验证大模型连接和后续 ERPNext
查询。页面要求助手气泡位于左侧、用户气泡位于右侧，使用接近 Codex 等现代 Agent 产品的
克制布局，并由现有 Docker Compose 服务直接托管。

## 已完成内容

- 新增响应式单页聊天工作台，入口为 `http://localhost:8001/`；
- 助手使用左侧浅色气泡，用户使用右侧深色气泡；
- 提供桌面导航栏、连接状态、模式切换、快捷问题、自动高度输入框和移动端适配；
- 所有 HTML、CSS、JavaScript 随 Agent 镜像本地提供，不依赖外部 CDN；
- 默认“模型对话”模式使用无工具 Agent，可测试模型回复和最近 10 条消息上下文；
- “ERPNext Agent”模式复用现有只读 Agent SSE，可显示工具调用开始和结束状态；
- 页面自动检查 OAuth Session，未登录时提示“登录 ERPNext”，所有对话请求携带 CSRF token；
- 新增 `/api/v1/chat/model/stream`，为已登录用户提供受保护的模型专用 SSE；
- 新增 `python -m erpnext_agent.ui_smoke`，自动创建临时 Session、访问页面、真实请求模型并
  删除测试 Session；
- Dockerfile 与 Compose 健康检查同时验证 `/health/ready` 和 `/` 页面。

## 使用方式

启动服务：

```bash
docker compose --env-file .env up --build -d
```

打开 `http://localhost:8001/`，点击“登录 ERPNext”完成 OAuth 登录。需要单纯验证模型时保持
“模型对话”；需要查询 ERPNext 时切换为“ERPNext Agent”。

命令行复现页面与真实模型联合检查：

```bash
docker compose --env-file .env exec -T agent \
  python -m erpnext_agent.ui_smoke
```
